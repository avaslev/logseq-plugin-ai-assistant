OpenAI-совместимый AI-агент прямо в [Logseq](https://logseq.com). Переписка хранится в графе: каждая сессия — отдельная страница в неймспейсе `ai_assistant/`, поэтому история, поиск и ссылки находят её как обычные заметки.

## Возможности

- Стриминг ответа в блок сессии в реальном времени
- Инструменты по графу: поиск страниц и блоков, задачи по статусам, чтение страниц и блоков, выделенный текст, запросы DSL/Datalog, дневные страницы, недавние страницы
- Веб-поиск без ключей: `web_search` и `fetch_page` через DuckDuckGo Lite
- Инструменты записи на открытой странице (по желанию): вставка, правка, удаление, перемещение блоков, свойства, создание страниц с подтверждением
- Скиллы — переиспользуемые инструкции в графе, явный вызов `/имя` или автовыбор моделью
- Редактируемый системный промпт на странице `ai_assistant/system`
- MCP-серверы с транспортом HTTP: подключение внешних инструментов
- Команды `/compress`, `/remove`, `/skill`; остановка и Retry, история сообщений, оценка токенов
- Большие вставки сворачиваются во вложения, чтобы не раздувать поле ввода
- Выбор модели на сессию и оформление под тему Logseq

## Установка

Из маркетплейса: `Plugins` → `Marketplace` → найдите `logseq-ai-graph-assistant`.

Вручную из исходников:

```bash
npm install && npm run build
```

Затем включите режим разработчика и выберите `Plugins` → `Load unpacked plugin` → корневую папку проекта. Подробности — в разделе [Установка](docs/install.md).

## Быстрый старт

1. `Settings` → `Plugin Settings` → `AI Assistant` → заполните **API base URL** (например, `http://localhost:1234/v1` для LM Studio)
2. Перезагрузите плагин и выберите **Default model**
3. Откройте правую панель Logseq и напишите первое сообщение

Подойдёт любой OpenAI-совместимый сервер: LM Studio, Ollama, OpenRouter, OpenAI и другие. Примеры и все параметры — в разделе [Настройки](docs/configuration.md).

## Приватность

У плагина нет собственной телеметрии. Запросы уходят только на ваш API-сервер; MCP-серверы и веб-инструменты обращаются к сети лишь тогда, когда включены и вызываются моделью. Сессии хранятся локально в вашем графе.
