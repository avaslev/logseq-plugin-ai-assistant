# Разработка

[← К README](../README.md)

## Требования

Node.js и npm.

## Команды

```bash
npm install
npm run dev     # дев-режим с HMR
npm run build   # прод-сборка (tsc && vite build)
npm test        # юнит- и интеграционные тесты (vitest)
npx eslint src  # линтер (отдельного npm-скрипта нет)
```

Подключение к Logseq: включите режим разработчика, затем `Plugins` → `Load unpacked plugin` и выберите корневую папку проекта. После изменений пересоберите `dist` и перезагрузите плагин.

## Релизы

Релизы автоматизированы через semantic-release в GitHub Actions при пуше в `master`:

- сообщения коммитов — conventional commits (`feat:`, `fix:`, `docs:`, `chore:` и т.д.), по ним определяется версия
- обновляются `CHANGELOG.md`, `package.json` и тег релиза
- в GitHub Release прикладывается zip: `dist`, `README.md`, `logo.svg`, `LICENSE`, `package.json`

## Структура

| Файл | Назначение |
|---|---|
| `src/main.tsx` | Регистрация плагина, иконка в тулбаре, стили, создание страницы системного промпта |
| `src/App.tsx` | Форма в панели: стриминг, подтверждения, история, вложения, селектор модели |
| `src/chat.ts` | Сессии и страницы графа, конвейер отправки, компрессия, удаление |
| `src/commands.ts` | Слэш-команды и автодополнение |
| `src/confirm.ts` | Механизм подтверждений |
| `src/format.ts` | Системный промпт и форматирование ответов под блоки Logseq |
| `src/http.ts` | HTTP-запросы с таймаутами и ретраями |
| `src/input.ts` | Вспомогательные функции поля ввода |
| `src/llm.ts` | Клиент OpenAI-совместимого API: SSE-стриминг, tool-loop, список моделей |
| `src/logseqTools.ts` | Инструменты графа, записи и создания страниц |
| `src/mcp.ts` | MCP-клиент с транспортом HTTP |
| `src/outline.ts` | Разбор outline в дерево блоков для вложенности на страницах |
| `src/paste.ts` | Сворачивание больших вставок во вложения |
| `src/settings.ts` | Схема настроек и загрузка моделей |
| `src/skills.ts` | Каталог скиллов и страница системного промпта |
| `src/strings.ts` | Подписи интерфейса |
| `src/tokens.ts` | Оценка токенов |
| `src/utils.ts` | Общие утилиты |
| `src/webTools.ts` | Веб-поиск и загрузка страниц |
| `src/index.css` | Tailwind и стили плагина |
| `tests/` | Тесты vitest, в том числе с мок-серверами OpenAI и MCP |

## Тесты

`npm test` запускает vitest. Тесты покрывают конвейер сообщений, инструменты графа, скиллы, MCP, веб-инструменты, вложения, токены и настройки; сетевые вызовы замоканы. Перед коммитом полезно прогнать `npm run build` — он включает проверку типов (`tsc`).
