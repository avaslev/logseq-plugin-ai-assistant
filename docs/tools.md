# Инструменты агента

[← К README](../README.md)

Инструменты включаются настройкой **Enable tools**. Они делятся на три группы: чтение графа, веб-поиск и запись на открытой странице. Найденные блоки агент цитирует ссылками `((uuid))`, когда это уместно.

## Чтение графа

Доступны при включённых **Enable tools**, только чтение.

| Инструмент | Что делает |
|---|---|
| `search_graph` | Ищет страницы и блоки по подстроке; возвращает `uuid` для ссылок |
| `search_tasks` | Список задач по статусу `TODO`, `DOING`, `NOW`, `LATER`, `WAITING`, `DONE` |
| `get_page` | Метаданные страницы по имени |
| `get_page_blocks` | Блоки страницы в порядке документа |
| `get_block` | Блок и его дочерние блоки по `uuid` |
| `get_current_page` | Страница, открытая у пользователя в основном редакторе, с первыми блоками |
| `get_selected_blocks` | Блоки, выделенные в редакторе |
| `query_blocks` | Запрос к графу: DSL (как `{{query}}`) или Datascript/Datalog |
| `search_journal` | Блоки дневных страниц за последние N дней (по умолчанию 7, максимум 90) |
| `get_recent_pages` | Недавно изменённые страницы с временем обновления |

Статусы задач — это маркеры блока, а не текст, поэтому `search_graph` их не находит; для статусов используйте `search_tasks`.

## Веб-поиск

Доступен при включённых **Enable tools**. Не требует ключей и внешних серверов — работает через DuckDuckGo Lite.

| Инструмент | Что делает |
|---|---|
| `web_search` | Поиск в интернете: до 8 результатов `{title, url, snippet}`, таймаут 10 с, одна повторная попытка при сетевых сбоях и 5xx |
| `fetch_page` | Загружает страницу и возвращает читаемый текст (без скриптов и разметки, ~8000 символов) |

Если нужен другой поисковик (SearXNG, Brave и т.п.), подключите его как MCP-сервер. MCP-инструменты с теми же именами перекрывают встроенные.

## Запись на открытой странице

Добавляются только при включённой настройке **Allow editing the open page**. Действуют исключительно на страницу, открытую в основном редакторе в момент запроса: попытка тронуть чужой `uuid` возвращает ошибку, страницы `ai_assistant/...` защищены.

| Инструмент | Что делает |
|---|---|
| `create_page` | Создаёт страницу графа (см. ниже) |
| `insert_block` | Вставляет блок в конец страницы или после указанного блока |
| `prepend_block` | Вставляет блок в начало страницы |
| `update_block` | Заменяет содержимое блока по `uuid` |
| `remove_block` | Удаляет блок вместе с дочерними |
| `move_block` | Перемещает блок до/после цели или последним ребёнком |
| `upsert_block_property` | Задаёт свойство `key:: value` на блоке |

### Создание страниц и согласие

`create_page` учитывает параметр `requested`:

- `requested: true` — пользователь явно попросил создать страницу в текущем запросе, страница создаётся сразу;
- `requested: false` — агент предлагает страницу сам, и в интерфейсе появляется подтверждение; при отказе агент продолжает без неё и не повторяет попытку.

Если страница с таким именем уже существует, она переиспользуется. Неймспейс `ai_assistant/` (сессии, скиллы, системный промпт) создавать через `create_page` нельзя.

## Скиллы

`use_skill` позволяет модели самой подгрузить скилл, когда запрос совпадает с его описанием. Каталог скиллов и инструмент добавляются только при включённых **Enable tools**. Подробнее — в разделе [Скиллы](skills.md).

## Безопасность

- Инструменты чтения не меняют граф
- Инструменты записи выключены по умолчанию и ограничены открытой страницей
- Разрушительные действия в интерфейсе требуют подтверждения
- MCP-серверы и веб-поиск получают данные, которые вы им отправляете; подключайте только доверенные серверы
