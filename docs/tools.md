# Инструменты агента

[← К README](../README.md)

Набор инструментов задаётся настройкой **Tools** (`off` / `lite` / `full`). По умолчанию — `lite`: только четыре инструмента чтения графа. Инструменты делятся на три группы: чтение графа, веб-поиск и запись на открытой странице. Найденные блоки агент цитирует ссылками `((uuid))`, когда это уместно.

| Пресет | Что доступно |
|---|---|
| `off` | ничего |
| `lite` (по умолчанию) | 4 инструмента чтения графа из таблицы ниже |
| `full` | все инструменты чтения, веб-поиск, MCP, каталог скиллов и `use_skill`; write-инструменты — дополнительно при включённой настройке **Allow editing the open page (full preset only)** |

## Надёжность вызовов

- Аргументы инструментов проверяются по схеме: плагин убирает обёртки Markdown-блоков и запятые на конце, приводит числа и логические значения к нужному типу, подставляет значения по умолчанию. Если обязательное поле отсутствует, инструмент не вызывается — модели возвращается короткая ошибка с ожидаемой схемой.
- Длинные результаты инструментов сжимаются перед отправкой модели: длинные строки обрезаются, большие массивы — до первых элементов с пометкой о пропущенном. JSON остаётся корректным.
- Если модель трижды вызывает один и тот же инструмент с теми же аргументами (или зацикливается на чередовании двух вызовов), плагин останавливает цикл и делает один финальный запрос без инструментов, чтобы модель ответила по уже полученным данным.

## Чтение графа

При пресете `lite` доступны только `search_graph`, `search_tasks`, `get_page` и `get_block`. Остальные инструменты этой таблицы — только в `full`.

| Инструмент | Что делает |
|---|---|
| `search_graph` | Ищет страницы и блоки по подстроке; возвращает `uuid` для ссылок |
| `search_tasks` | Список задач по статусу `TODO`, `DOING`, `NOW`, `LATER`, `WAITING`, `DONE` |
| `get_page` | Метаданные и блоки страницы по имени; без `page` — открытая сейчас страница, `offset` — постраничное чтение, `meta_only` — только метаданные |
| `get_block` | Блок с дочерними блоками по `uuid`; `outline: true` — всё поддерево как outline с `blockRefs` |
| `get_selected_blocks` | Блоки, выделенные в редакторе |
| `query_blocks` | Запрос к графу: DSL (как `{{query}}`) или Datascript/Datalog |
| `search_journal` | Блоки дневных страниц за последние N дней (по умолчанию 7, максимум 90) |
| `get_recent_pages` | Недавно изменённые страницы с временем обновления |

Статусы задач — это маркеры блока, а не текст, поэтому `search_graph` их не находит; для статусов используйте `search_tasks`.

Старые имена `get_page_blocks`, `get_block_subtree` и `get_current_page` остаются рабочими алиасами `get_page` и `get_block` (без новых параметров), чтобы старые диалоги не ломались.

## Веб-поиск

Доступен только при пресете `full`. Не требует ключей и внешних серверов — работает через DuckDuckGo Lite.

| Инструмент | Что делает |
|---|---|
| `web_search` | Поиск в интернете: до 8 результатов `{title, url, snippet}`, таймаут 10 с, одна повторная попытка при сетевых сбоях и 5xx |
| `fetch_page` | Загружает страницу и возвращает читаемый текст (без скриптов и разметки, ~8000 символов) |

Если нужен другой поисковик (SearXNG, Brave и т.п.), подключите его как MCP-сервер. MCP-инструменты с теми же именами перекрывают встроенные.

## Запись на открытой странице

Добавляются только при пресете `full` **и** включённой настройке **Allow editing the open page (full preset only)**. Действуют исключительно на страницу, открытую в основном редакторе в момент запроса: попытка тронуть чужой `uuid` возвращает ошибку, страницы `ai_assistant/...` защищены.

| Инструмент | Что делает |
|---|---|
| `create_page` | Создаёт страницу графа (см. ниже) |
| `append_journal` | Дописывает заметку в журнальную страницу по дате — без открытой страницы |
| `insert_block` | Вставляет один плоский блок в конец страницы или после указанного блока |
| `insert_outline` | Вставляет структурированный outline как реальные вложенные блоки |
| `prepend_block` | Вставляет один плоский блок в начало страницы |
| `update_block` | Заменяет содержимое одного блока по `uuid` |
| `remove_block` | Удаляет блок вместе с дочерними |
| `move_block` | Перемещает блок до/после цели или последним ребёнком |
| `upsert_block_property` | Задаёт свойство `key:: value` на блоке |

`insert_block`, `prepend_block` и `update_block` пишут **один плоский блок**: Markdown-списки внутри превращаются в `•`, заголовки снимаются. Это тот же формат, что и у ответа агента в сессии. Для настоящей вложенности используйте `insert_outline`.

Каждый инструмент записи перечитывает блок после записи и возвращает фактическое содержимое; если Logseq не подтвердил запись, инструмент возвращает ошибку. `ok` в ответе инструмента означает, что изменение реально произошло. После вставки плагин прокручивает страницу к новому блоку — правка видна сразу, даже если Logseq откладывает перерисовку страницы.

### Заметки в журнал

`append_journal` дописывает заметку в журнальную страницу по дате: `today`, `yesterday`, `tomorrow` или `YYYY-MM-DD`. Работает без открытой страницы — удобно, когда вы на обзорной странице журналов или в другом месте графа. Если страницы за дату ещё нет, плагин пытается её создать. Инструмент пишет только в журнальные страницы, заметка — один плоский блок.

### Вложенность на странице

`insert_outline` принимает outline с отступами: 2 пробела или таб на уровень, маркеры `-`, `*`, `+`, `1.`, `1)`.

- Верхний уровень и один уровень детей становятся реальными блоками.
- Всё, что глубже, сворачивается в `•`-строки внутри блока-родителя, чтобы не плодить лишние уровни.
- Цепочка «родитель → единственный ребёнок» схлопывается в один блок.
- `after_uuid` вставляет outline после указанного блока как соседей, `parent_uuid` — как детей указанного блока; вместе их передавать нельзя.
- Лимит — 100 блоков на один вызов. Если outline больше, разбейте его на несколько вызовов.

Иерархию стоит использовать только для реальных разделов и подпунктов. Простой список лучше оставить одним блоком с `•`-строками.

### Создание страниц и согласие

`create_page` учитывает параметр `requested`:

- `requested: true` — пользователь явно попросил создать страницу в текущем запросе, страница создаётся сразу;
- `requested: false` — агент предлагает страницу сам, и в интерфейсе появляется подтверждение; при отказе агент продолжает без неё и не повторяет попытку.

Для структурированной новой страницы вместо `first_block` передайте `outline` в том же формате, что и у `insert_outline`. `first_block` и `outline` взаимоисключающие: `first_block` создаёт один плоский блок, `outline` — дерево блоков.

Если страница с таким именем уже существует, она переиспользуется. Неймспейс `ai_assistant/` (сессии, скиллы, системный промпт) создавать через `create_page` нельзя.

## Скиллы

`use_skill` позволяет модели самой подгрузить скилл, когда запрос совпадает с его описанием. Каталог скиллов и инструмент добавляются только при пресете `full`. Подробнее — в разделе [Скиллы](skills.md).

## Безопасность

- Инструменты чтения не меняют граф
- Инструменты записи выключены по умолчанию и ограничены открытой страницей
- Подтверждение запрашивается при удалении сессии и при создании страницы, предложенной агентом; инструменты записи подтверждения не требуют — они ограничены открытой страницей и проверяют результат записи
- MCP-серверы и веб-поиск получают данные, которые вы им отправляете; подключайте только доверенные серверы
