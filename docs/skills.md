# Скиллы

[← К README](../README.md)

Скилл — это страница-инструкция в графе, которую модель подгружает по мере надобности. Так можно хранить повторяющиеся сценарии: стиль ответов, шаблоны заметок, предметные правила.

## Устройство скилла

- Расположение: `ai_assistant/skills/<имя>` — одна страница на скилл
- Первый блок — метаданные: `AI Skill`, внутри свойства `name::` (отображаемое имя) и `description::` (когда применять)
- Остальные блоки страницы — сама инструкция

Быстрое создание: команда [`/skill`](commands.md#skill) создаёт страницу с шаблоном и открывает её для заполнения.

Пример:

```
AI Skill
name:: Рецензия статьи
description:: Использовать, когда нужно разобрать научную статью

Читай статью и выделяй: гипотезу, метод, данные, результат, ограничения.
Пиши кратко, списком, со ссылками на блоки.
```

## Способы вызова

**Явный** — `/имя-скилла текст запроса`. Инструкция сразу попадает в системный промпт, а запрос виден в сессии.

**Автоматический** — при включённых **Enable tools** модель видит каталог скиллов (имя и описание) в системном промпте и сама вызывает `use_skill`, когда запрос явно совпадает с описанием. Для посторонних запросов инструмент не вызывается.

При явном вызове каталог и `use_skill` не добавляются — инструкция уже загружена. Правки страниц скиллов подхватываются при следующем вызове, а автодополнение обновляется с кэшем до 3 секунд.

## Системный промпт

Базовые правила поведения заданы в плагине, но их можно дополнить собственной страницей:

- Страница: `ai_assistant/system`
- Создаётся автоматически при первом запуске плагина и открыта для редактирования
- Если её удалить, плагин создаст страницу заново
- Содержимое страницы добавляется к базовому промпту; если оставить страницу пустой, действуют только базовые правила
- Не добавляйте в неё текущую дату вручную — она подставляется при каждом запросе

Через эту страницу удобно задавать общий стиль: язык ответов, формат списков, правила цитирования, обращение к пользователю.
