# Настройки

[← К README](../README.md)

Все параметры находятся в `Settings` → `Plugin Settings` → `AI Assistant`.

| Параметр | По умолчанию | Описание |
|---|---|---|
| **API base URL** | `http://localhost:1234/v1` | OpenAI-совместимый эндпоинт |
| **API token** | пусто | Bearer-токен; для локальных серверов обычно не нужен |
| **Default model** | первая доступная | Модель для новых сессий; список загружается с сервера |
| **History blocks** | `20` | Сколько последних блоков сессии отправлять модели как контекст |
| **Enable tools** | включено | Инструменты агента: работа с графом, веб-поиск, MCP, `use_skill` |
| **Allow editing the open page** | выключено | Инструменты записи на странице, открытой в основном редакторе |
| **MCP servers (JSON)** | `[]` | Массив MCP-серверов с транспортом HTTP |

## Примеры API base URL

| Сервер | URL |
|---|---|
| LM Studio | `http://localhost:1234/v1` |
| Ollama | `http://localhost:11434/v1` |
| OpenRouter | `https://openrouter.ai/api/v1` (нужен **API token**) |
| OpenAI | `https://api.openai.com/v1` (нужен **API token**) |

После изменения **API base URL** перезагрузите плагин, чтобы обновить список моделей.

## Логика моделей

- Модель из настроек используется для новых сессий
- В футере формы можно выбрать другую модель — выбор действует на текущую сессию и записывается в мета-блок `model::` при следующей отправке
- При повторном открытии сессии подхватывается модель из мета-блока; если её нет на сервере — используется модель по умолчанию
- Список фильтруется: embedding-, rerank-, moderation-, TTS- и image-модели скрыты

## Контекст и память

**History blocks** ограничивает, сколько последних блоков сессии получает модель. Уменьшайте значение (например, до 8–12), если:

- модель упирается в лимит контекста;
- на слабом железе запросы выполняются слишком медленно;
- локальная модель падает из-за нехватки памяти.

Для сжатия уже накопленной сессии используйте команду [`/compress`](commands.md#compress).

## Инструменты

- **Enable tools** включает инструменты графа, веб-поиск, MCP и автоматический выбор скиллов. На слабом железе их лучше отключить: каталог инструментов заметно увеличивает контекст запроса.
- **Allow editing the open page** добавляет инструменты записи. Они действуют только на страницу, открытую в основном редакторе, а страницы `ai_assistant/...` защищены от изменений.

Подробнее — в разделе [Инструменты агента](tools.md).

## MCP-серверы

Значение — JSON-массив объектов:

```json
[
  {
    "name": "my-mcp",
    "url": "http://localhost:8000/mcp",
    "headers": { "Authorization": "Bearer x" }
  }
]
```

Поддерживаются транспорты Streamable HTTP и SSE. Подробнее — в разделе [MCP-серверы](mcp.md).
