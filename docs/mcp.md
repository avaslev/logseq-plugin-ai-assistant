# MCP-серверы

[← К README](../README.md)

MCP (Model Context Protocol) позволяет подключить внешние инструменты: файлы, базы данных, API и готовые серверы из экосистемы. Плагин работает с транспортами HTTP — Streamable HTTP и SSE.

## Настройка

В `Settings` → `Plugin Settings` → `AI Assistant` заполните **MCP servers (JSON)** массивом серверов:

```json
[
  {
    "name": "fs",
    "url": "http://localhost:8000/mcp",
    "headers": { "Authorization": "Bearer x" }
  }
]
```

Поле `headers` необязательно. Инструменты всех серверов добавляются к встроенным и доступны агенту при включённой настройке **Enable tools**; MCP-инструменты с теми же именами перекрывают встроенные.

## Локальные stdio-серверы

Плагин выполняется в песочнице браузера и не может запускать процессы. Для stdio-серверов поднимите HTTP-мост, например через `supergateway`:

```bash
npx supergateway --stdio "npx -y @modelcontextprotocol/server-filesystem /path/to/dir" --port 8000
```

Затем укажите в настройках:

```json
[{ "name": "fs", "url": "http://localhost:8000/mcp" }]
```

## Проверка

- Сервер должен отвечать на `POST` с заголовком `Accept: application/json, text/event-stream`
- Если инструменты не появились, проверьте доступность URL и перезагрузите плагин
- Ошибки соединения с MCP-сервером не блокируют чат: остальные инструменты продолжают работать

## Безопасность

- MCP-серверы получают содержимое ваших запросов и результаты работы инструментов — подключайте только доверенные серверы
- Токены в `headers` хранятся в настройках плагина в открытом виде
- Отключите **Enable tools**, если не хотите, чтобы модель обращалась к внешним сервисам
