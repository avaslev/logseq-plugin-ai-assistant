# Устройство плагина

[← К README](../README.md)

Раздел для тех, кто хочет понимать внутреннюю механику или участвовать в разработке.

## Сессии в графе

- Каждая сессия — страница `ai_assistant/<YYYYMMDD_HHMMSS>_<slug>`, где slug — начало первого сообщения
- Первый блок страницы — метаданные `model::` и `started::`
- Сообщения пользователя и ответы ассистента — обычные блоки страницы; ответы помечены префиксом `✦ `
- При открытии сессии роли восстанавливаются по префиксу `✦ `
- Сессии, созданные до появления маркера, читаются как сообщения пользователя — поддержки нет

Хранение в графе даёт историю, поиск и ссылки `((uuid))` без внешней базы.

## Конвейер отправки

1. Текст из формы (с развёрнутыми вложениями) записывается в блок сессии
2. Собирается контекст: последние N блоков по настройке **History blocks**
3. Собирается системный промпт: базовые правила + текущая дата + пользовательская страница `ai_assistant/system` + каталог скиллов (если включены инструменты и нет явного вызова скилла)
4. Запрос уходит на OpenAI-совместимый API со стримингом SSE
5. Если модель вызывает инструменты, выполняется tool-loop: результат возвращается модели, и генерация продолжается
6. Ответ дописывается в блок сессии по мере поступления; остановка прерывает запрос через `AbortController`

Ретраи: сетевые сбои, таймауты и ответы 5xx повторяются один раз после короткой паузы. Ошибки 4xx не повторяются.

## Компрессия

`/compress` вычитывает все блоки сессии, просит модель построить сводку и заменяет историю одним блоком. Мета-блок `model::`/`started::` сохраняется. Заголовок сводки модель формирует на языке диалога.

## Подтверждения

Действия, меняющие граф, проходят через общий механизм подтверждений (`confirm.ts`):

- UI подписывается на запросы подтверждения и показывает модальное окно
- Ответ возвращается промисом, поэтому код инструмента просто ждёт решения пользователя
- Подтверждение привязано к сигналу отмены: остановка генерации отклоняет промис
- В среде без UI (тесты, headless) подтверждение автоматически считается данным

Так работают удаление сессии и создание страницы, предложенной агентом.

## Интерфейс

Форма — React-приложение внутри iframe, который плагин показывает внизу правой панели Logseq. Плагин измеряет размеры панели и подстраивает высоту iframe под содержимое. При подтверждении iframe временно раскрывается на всю высоту панели, рисует затемнение и центрированное модальное окно, после чего возвращается к обычному размеру. Оформление опирается на CSS-переменные темы Logseq (`--ls-*`).

## Модели

Список моделей загружается с сервера и фильтруется: embedding-, rerank-, moderation-, TTS- и image-модели скрыты. Выбранная модель хранится в мета-блоке сессии и влияет только на неё.
