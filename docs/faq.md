# Частые вопросы

[← К README](../README.md)

### Как ассистент рисует Excalidraw-схемы?

Инструмент `create_drawing` создаёт файл в `draws/` и вставляет в открытую страницу блок `[[draws/<имя>.excalidraw]]` — появляется встроенный холст Excalidraw с фигурами (прямоугольники, эллипсы, стрелки, текст), который можно дальше редактировать вручную. Функция опирается на недокументированное внутреннее API Logseq (`save-excalidraw!`), поэтому может перестать работать в будущих версиях Logseq; холсты whiteboard (tldraw) из плагина создавать нельзя — для них нет ни публичного, ни стабильно вызываемого внутреннего API.

### Можно ли подключить локальные stdio MCP-серверы?

Напрямую — нет, плагин работает в песочнице браузера. Используйте HTTP-мост, например `supergateway`; пример есть в разделе [MCP-серверы](mcp.md#локальные-stdio-серверы).

### Почему старые сессии читаются неправильно?

Сессии до появления маркера `✦ ` не поддерживаются: плагин не может отличить ответы ассистента от сообщений пользователя. Начните новую сессию.

### Сколько раз агент может обращаться к модели?

Один запрос на ответ плюс по одному на каждый вызов инструментов, пока не будет получен финальный текст. Число раундов рассчитывается автоматически из окна контекста модели: плагин определяет его у LM Studio, Ollama, llama.cpp, OpenRouter и vLLM, а если сервер его не сообщает — использует запас 32k. Жёсткий потолок — 24 раунда. Если раунды исчерпаны, а модель всё ещё вызывает инструменты, плагин делает один финальный запрос без инструментов: модель кратко отчитывается, что сделано и что осталось. Если финального текста нет и тогда, в сессии появится пометка «completed with tools».

### Модель упирается в лимит контекста или всё работает медленно

- Уменьшите **History blocks** (по умолчанию 20)
- Отключите **Enable tools** — каталог инструментов и MCP заметно увеличивают контекст
- Сожмите накопленную сессию командой `/compress`
- Используйте модель поменьше или квантованную версию

### Не загружается список моделей

Проверьте **API base URL** и доступность сервера, затем перезагрузите плагин: список моделей обновляется при старте.

### Ошибки сети или CORS

Локальный сервер должен разрешать запросы из приложения Logseq. У LM Studio и Ollama обычно всё работает из коробки; для других серверов проверьте настройки CORS. Для облачных API укажите **API token**.

### Работает ли плагин офлайн?

Да, если API-сервер локальный (LM Studio, Ollama). Веб-инструменты и MCP при этом требуют сети — их можно не включать.

### Куда уходят мои данные?

- Запросы и контекст сессии — на ваш API-сервер из настроек
- MCP-серверы получают содержимое запросов и результаты инструментов, если они включены
- `web_search` и `fetch_page` обращаются к DuckDuckGo и запрошенным страницам — только когда модель вызывает эти инструменты
- Никакой собственной телеметрии и внешних сервисов у плагина нет

### Где хранятся сессии и как их удалить?

Сессии — страницы графа в неймспейсе `ai_assistant/`. Удалить текущую сессию можно командой `/remove` (с подтверждением), остальные — как обычные страницы Logseq. Страницу системного промпта `ai_assistant/system` и скиллы можно редактировать и удалять — плагин восстановит системный промпт при следующем запуске.

### Как изменить поведение ассистента?

Отредактируйте страницу `ai_assistant/system` — её содержимое добавляется к базовому промпту. Для отдельных сценариев создавайте скиллы через `/skill`. Подробнее — в разделе [Скиллы](skills.md).

### Плагин поддерживает мобильный Logseq?

Ориентирован на десктопное приложение: панель ввода и загрузка локальных сборок рассчитаны на него. На мобильных поведение не гарантируется.
